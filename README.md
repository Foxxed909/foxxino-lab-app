# FOXXINO Lab App

Static picker for FOXXINO jailbreak suites.

## Use
1. Choose **model family**
2. Filter by **resistance** / search
3. Click a **suite**
4. **Copy prompt** → paste in your client
5. On refuse → **Copy recovery block**

## Deploy on Vercel (one click)
1. https://vercel.com/new
2. Import `Foxxed909/foxxino-lab-app`
3. Framework: Other / static — no build command
4. Output: root
5. Deploy

Or CLI:
```bash
npx vercel --yes
```
